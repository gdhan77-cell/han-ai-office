# 한경동 AI 오피스 (han-ai-office)

5층짜리 가상 AI 오피스를 한 장의 HTML로 만든 웹앱입니다. 부서별 AI 직원에게 일을 맡기고, 올라온 보고서를 대표실 결재 줄에서 승인·반려합니다.

- 주소: https://gdhan77-cell.github.io/han-ai-office/
- 파일: `index.html` (단일 파일, 외부 CDN·폰트·스크립트 의존성 없음)

## 층 구성

| 층 | 부서 |
|---|---|
| 5F 대표실 | 결재 줄 · 대표님 차례 |
| 4F 명리·사업 | 명리·사주분석팀, 타로·고객응대팀, SNS·출판·홍보팀 |
| 3F 교육·콘텐츠 | 시낭송교육·콘텐츠팀, 유튜브·영상기획팀, 디자인·카드뉴스팀, 시극팀, 시치유팀 |
| 2F 창작·집필 | 소설·창작팀, 퇴고·교정팀, 평론·자료조사팀 |
| 1F 로비·비서실 | 비서실(연지 실장), 총무·일정팀, 법무팀 |

## 쓰는 법

1. 오른쪽 **지시하기**에서 부서·담당 AI·지시 내용을 적고 보냅니다. (Ctrl+Enter)
2. 직원이 보고서를 올리면 5F 대표실 결재 줄과 **대표님 기다림**에 나타납니다.
3. **승인**하면 보고서의 ‘대표님 확인 필요’ 항목이 **대표님 차례**로 넘어갑니다. **반려**하면 사유를 적어 바로 재작업을 시킬 수 있습니다.
4. 다른 부서가 끝낸 보고서는 **넘길 자료**로 골라 다음 지시에 함께 넘길 수 있습니다(최대 5개).

## 사진으로 아바타 바꾸기

- **설정 → 🖼️ 대표님·직원 사진**에서 5F 대표실과 14개 부서 직원의 사진을 줄마다 [`사진 올리기`] · [`기본 그림으로`]로 바꿀 수 있습니다.
- 부서 상세 드로어(부서 카드 클릭)나 5F 대표실 카드의 **📷** 버튼으로도 바로 올릴 수 있습니다.
- 올린 사진은 브라우저에서 가운데를 정사각형으로 잘라 **160×160 JPEG(품질 0.82)** 로 줄여 localStorage에만 저장합니다. 원본 파일은 바뀌지 않고, 5MB 저장 한도를 넘기지 않습니다.
- 사진을 넣은 자리에는 SVG 아바타 대신 그 사진이 건물 카드·대표실·업무 드로어에 같은 모양(둥근 사각, 꽉 채움)으로 보입니다.
- [`기본 그림으로`]를 누르면 원래 SVG 아바타로 돌아갑니다.

## AI 연결

- 키 없이도 **데모 모드**로 전 과정을 체험할 수 있습니다.
- **설정 → AI 연결**에 Anthropic·OpenAI·Google·Perplexity 키를 넣으면 부서별 담당 AI가 실제로 답합니다.
- 키 하나만 있으면 **단일 키 대행**으로 전 부서 역할을 그 AI가 맡습니다.
- 키는 브라우저(localStorage)에만 저장되며, 이 저장소나 다른 곳으로 전송되지 않습니다.

## 저장

모든 업무·대화·보고서·설정은 사용하는 브라우저의 localStorage에 자동 저장됩니다. 남길 보고서는 각 보고서의 `.md`·`.txt` 내려받기로 보관하세요.
